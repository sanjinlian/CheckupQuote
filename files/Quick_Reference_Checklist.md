## 💰 費用計算公式

### 報價單自動計算流程

```
1. 細項複價 = 數量 × 單價
   例: 5 尺 × 2500 = 12,500 元

2. 工班小計 = 該工班所有細項複價之和

3. 工程費小計 = 全部工班小計之和
   例: 保護 + 木作 + 油漆 + ... = 500,000 元

4. 管理監工費 = 工程費小計 × 30%
   例: 500,000 × 0.30 = 150,000 元

5. 小計 = 工程費小計 + 管理監工費
   例: 500,000 + 150,000 = 650,000 元

6. 設計師利潤 = 小計 × 利潤加成率（可變，默認35%）
   例: 650,000 × 0.35 = 227,500 元

7. 稅前小計 = 小計 + 利潤
   例: 650,000 + 227,500 = 877,500 元

8. 營業稅 = 稅前小計 × 5%
   例: 877,500 × 0.05 = 43,875 元

9. 最終報價 = 稅前小計 + 營業稅
   例: 877,500 + 43,875 = 921,375 元
```

### 範例：安和吳公館報價

```
工程費小計          500,000 元
管理監工費(30%)      150,000 元
─────────────────────────────
小計               650,000 元
設計師利潤(35%)      227,500 元
─────────────────────────────
稅前小計            877,500 元
營業稅(5%)           43,875 元
═════════════════════════════
合計               921,375 元
```

## 🐛 常見錯誤和解決方案

### 錯誤 1：「無法讀取工班模板」

**原因：** Google Apps Script 連接失敗

**解決：**
1. 檢查 API_BASE 是否正確
2. 確認 Google Apps Script 已部署
3. 清除瀏覽器快取，重新整理

### 錯誤 2：「生成 Excel 失敗」

**原因：** Google Drive 權限或資料夾不存在

**解決：**
1. 確認「三今設計_報價單系統」資料夾已建立
2. 檢查 QUOTATION_FOLDER_ID 是否正確
3. 確認資料夾權限為可編輯

### 錯誤 3：「自訂工班無法保存」

**原因：** Google Sheet 共用設置不當

**解決：**
1. 重新共用 Google Sheet 給服務帳戶
2. 確認「自訂工班庫」工作表已建立
3. 檢查工班名稱是否有特殊符號

### 錯誤 4：「版本記錄不顯示」

**原因：** 版本歷史記錄工作表未初始化

**解決：**
1. 在 Apps Script 中手動執行 `initializeSheets()`
2. 重新生成報價單

## 📱 使用指南（給業務人員）

### 新增報價單的 5 步驟

1. **打開系統**
   - 瀏覽器輸入：`https://sanjin-quotation.netlify.app`

2. **填入案件信息**
   - 案件名稱：如「安和吳公館室內設計」
   - 坪數：如「48」
   - 利潤率：保持默認 0.35 (35%)

3. **勾選工班**
   - 根據案件需求勾選工班
   - 設計費會自動勾選（必選項）

4. **編輯細項**
   - 逐個工班編輯細項
   - 可修改數量、單價，或新增/刪除細項
   - 系統會自動計算複價

5. **生成報價**
   - 預覽費用計算
   - 添加版本備註（可選）
   - 點擊「生成並上傳 Excel」
   - 檔案自動儲存到 Google Drive

**報價單自動版本控制：** 每次生成都會自動保存版本，可隨時查閱和下載舊版本
