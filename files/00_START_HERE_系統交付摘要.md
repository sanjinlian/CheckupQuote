```
✅ 每個工班多個預設細項
✅ 自動檢測必選項（設計費）
✅ 支持新增自訂工班（自動驗證+保存範本）
```

### ✨ 細項編輯
```
✅ 編輯數量、單價、單位
✅ 新增 / 刪除細項
✅ 複價自動計算
✅ 市場行情參考提示
```

### ✨ 自動計算
```
✅ 複價 = 數量 × 單價
✅ 管理費 = 小計 × 30%
✅ 利潤 = (小計 + 管理費) × 35%（可變）
✅ 稅金 = 稅前小計 × 5%
✅ 最終報價 = 稅前小計 + 稅金
```

### ✨ 版本管理
```
✅ 自動保存到 Google Drive
✅ 自動年月資料夾整理
✅ 自動版本記錄（含修改內容）
✅ 可下載任何歷史版本
```

## ⚙️ 快速配置（只需改 3 個值）

### 1️⃣ Google Sheet ID
```
從 Google Sheet URL 複製：
https://docs.google.com/spreadsheets/d/[複製這個]/edit
```
**填入位置：** `GoogleAppsScript_Backend.js` 第 7 行

### 2️⃣ Google Drive 資料夾 ID
```
建立「三今設計_報價單系統」資料夾 → 右鍵複製連結
https://drive.google.com/drive/folders/[複製這個]
```
**填入位置：** `GoogleAppsScript_Backend.js` 第 10 行

### 3️⃣ Google Apps Script Web App URL
```
在 Apps Script 中：部署 → 複製整個 URL
https://script.google.com/macros/d/...
```
**填入位置：** `QuotationSystem_Frontend.jsx` 第 8 行
