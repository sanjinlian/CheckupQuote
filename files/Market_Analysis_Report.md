## 📝 Excel 報價單中的新增欄位

建議在 Google Sheet 和 Excel 報價單中新增：

```
| 原有欄位 | 新增欄位 | 說明 |
|---------|---------|------|
| 項目名稱 | 市場行情範圍 | 參考資訊，不列印 |
| 單價 | 價格評估 | ⭐等級，可選列印 |
| 複價 | 成本工資(選用) | 參考成本，內部用 |
| 備註 | 工法說明(選用) | 補充說明 |
```
